# SQL-COVID-19-Data-Exploration

This project involves an exploratory analysis of global COVID-19 data using SQL. By querying datasets on COVID-19 cases and vaccinations, the project aims to uncover insights into infection rates, mortality, and vaccination progress across different countries and continents.

## Environment Setup

1. Install Microsoft SQL Server 2019 and SQL Server Management Studio (SSMS) 2022.​
2. Create a database named Portfolio Project.​
3. Import the CovidDeaths.csv and CovidVaccinations.csv datasets into the database using the "Import Data" feature in SSMS.​

## Skills Demonstrated

-Data Cleaning and Transformation​
-Joins and Subqueries​
-Common Table Expressions (CTEs)​
-Window Functions​
-Aggregate Functions​
-Creating Views and Temporary Tables​

## Key Analyses

- Calculated death percentages relative to total cases.​
- Identified countries with the highest infection rates per population.​
- Analyzed vaccination rollouts and their correlation with infection rates.​
- Examined global trends and continent-level statistics.

## Conclusion

This project demonstrates the application of SQL in analyzing real-world datasets to derive meaningful insights. It serves as a valuable addition to a data analyst's portfolio, showcasing proficiency in data exploration and SQL querying.
